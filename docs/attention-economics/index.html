Attention Economics

Human attention is a priced resource. Find the optimal escalation policy — and measure trust.

1The problem

Agents either interrupt humans constantly (attention exhaustion) or act autonomously on high-stakes decisions (accountability failure). Escalation thresholds are set by gut feel; nobody prices the trade-off between interruption cost and error cost, and nobody measures whether the human's trust matches the agent's actual reliability.

2The current gap

Ask-vs-act is treated as a UX preference, not an optimization problem. Over-trust and under-trust are both failures with different cost signatures — unmeasured, unmanaged.

3How the solution addresses it

A decision-stream simulator (lognormal stakes, calibrated/miscalibrated confidence) with a fallible human principal (95% accurate), five escalation policies (always/never ask, fixed threshold, stakes-adjusted EV rule, budget-aware knapsack), a total-cost model (asks × interruption cost + unaudited errors × stakes × error cost), and trust calibration measurement (over/under-trust indices vs the EV reference).

4Architecture

Blueprint of the Attention Economics architecture. See the repo for the full implementation.

6Insights

  • Price the human's fallibility. The textbook rule assumes a perfect human and is systematically ~0.05 too trusting.
  • Overconfidence is 6x worse than underconfidence. Same ECE magnitude, wildly different cost — calibrate directionally.
  • Bankruptcy is about order, not volume. First-come truncation starves high-stakes decisions; knapsack doesn't.
