# Agentic Systems Lab

Six original, implemented agentic-AI systems — each with architecture,
working code, seeded experiments, measured results, and honest conclusions.
Built as a portfolio of senior AI architecture work: the emphasis is on
*decision-making under uncertainty*, *coordination*, and *reliability*,
not on prompt tricks.

## Projects

| # | Project | What it is | Key result |
|---|---|---|---|
| 01 | [meridian-orchestration](01-meridian-orchestration/) | Multi-orchestrator multi-agent system: vertical hierarchy + horizontal blackboard + online decision optimization (contextual Thompson sampling) | Learned router matches a hand-tuned tiering policy (89.6% vs 88.8% success) with zero hand-tuning |
| 02 | [sentinel-ledger](02-sentinel-ledger/) | Hash-chained evidence ledger + deterministic replay engine for agent decisions | 600/600 exact replays; 100% detection on seed/tool/tamper faults |
| 03 | [forge-inference](03-forge-inference/) | Discrete-event simulator of LLM inference serving; static vs continuous vs SRPT scheduling | Continuous batching: 9.2× lower mean latency at high load; SRPT cuts mean 34% but starves p99 |
| 04 | [skillbridge-mcp](04-skillbridge-mcp/) | Model-agnostic framework for reusable AI skills: portable packages, versioned registry, MCP-style capability broker, model adapters, governance, cross-model eval | 2× lower cross-model variance vs per-provider prompts; framework pays off from 2+ models |
| 05 | [collective-memory-fabric](05-collective-memory-fabric/) | Governed collective memory protocol: versioned claims, evidence-weighted quorum reconciliation, expiry, revocation | 0% wrong-answer rate under sustained misinformation injection; weakest model family 69% → 95% |
| 06 | [healflow](06-healflow/) | Self-healing workflow runtime: contracts, checkpoints, causal diagnosis, smallest-viable repair, verified recovery, repair memory | 6/6 safe outcomes; naive replan triple-charges a payment workflow |

## Running everything

Each project is self-contained:

```bash
cd 01-meridian-orchestration
python3 experiments/run_experiments.py   # regenerates results/results.md + charts.png
```

Requires Python 3.10+, `numpy`, `matplotlib`. Tests live in each
project's `tests/` and run without extra dependencies:

```bash
python3 -c "import sys; sys.path.insert(0,'tests'); import test_smoke; [getattr(test_smoke,n)() for n in dir(test_smoke) if n.startswith('test_')]"
```

## Layout per project

```
<project>/
  README.md          # problem, architecture, experiments, results, conclusions
  src/               # the implementation
  experiments/       # run_experiments.py — the benchmark
  results/           # results.md (tables) + charts.png (generated)
  tests/             # smoke tests
```

## Notes

- All agents, tools, and faults are **simulated with seeded RNG**. The
  benchmarks measure *architectural and protocol* tradeoffs, not production
  model behavior. Seeds are documented in each experiment runner.
- All six systems are original implementations built for this repo.
- Results tables are generated by the experiment runners — re-running
  reproduces them exactly.
